| 欄 | 記入例 |

| 実行条件 | EX-v2、模擬データ、固定計画EX-TP01 v1。想定の観測時点は例示日10:00〜10:20。実接続のTC-03は許可対象外である。 |

| 証拠 | EX-E01はID一致の出力、EX-E02は欠落時の画面とデータの差、EX-N03は未実施理由の記録という架空の対応。実在する証拠としてリンクしない。 |
| 完全性 | ケース削除、期待値の変更、都合の良い試行だけの選択は行っていないという設定。実案件では元計画との差分・再試行・欠測・切断を示す。 |
| 受入への影響 | REQ-01の一部未達が残り、受入不可の判断材料となる。実接続はNOT EVALUABLEであり、不合格結果とも合格結果とも混ぜない。Aが処置を判断する。 |
