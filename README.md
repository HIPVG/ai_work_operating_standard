# ai_work_operating_standard

AIを含む作業を、目的・権限・証拠・受入の曖昧さから守るための、公開の実務運用標準です。

このリポジトリには、規範となる運用標準、成果物の必要十分性に関する補助資料、ならびに選択・統合して使うためのテンプレート群を収録しています。テンプレートの一括作成や、既存のプロジェクト管理・法務判断・組織上の権限を置き換えることは意図していません。

自由に利用・参照・適用してください。

自組織への導入、AI支援開発の統制設計、個別案件向けの作業設計、契約・調達の前提整理などで支援が必要な場合は、商用のご相談も歓迎します。

## 現行版と版管理

現行規範は v1.1。上記の入口と、そこから参照する同版の`normative/`各節を一つの標準として扱う。旧統合版v1.0は[旧版](01-ai_work_operating_standard_integrated_v1_0_2026-09.md)として保持し、現行の指示には使わない。参考資料やテンプレートは規範を上書きしない。

メジャー番号は1に固定し、公表する改訂ごとに小数点以下の連番を一つ進める（v1.0→v1.1→v1.2）。規範の変更、規範の追加、編集上の修正のいずれも版を上げ、変更記録で種類と旧版への影響を区別する。版番号だけから適合性や効果を推定しない。本文の版、現行ファイル名、README、改訂記録を同時に更新する。旧版の内容はGitコミットと旧版ファイルで参照し、旧版への既存URLを壊さない。

v1.1では規範の適用条件と既存の8項目・28原則・P/Eチェックを維持し、読込入口の短縮、用途別の分割、案件固有付録の分離、文の区切り、版表示の整合を行った。規範レベルの全面分類、特定製品のフック導入、実効性の認定は行っていない。

v1.1の変更対象と確認範囲は[改訂記録](support/CHANGE_RECORD_v1_1_2026-10-06.md)を参照する。
