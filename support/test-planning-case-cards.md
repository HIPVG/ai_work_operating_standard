# 検証方針・テスト計画のケース別カード

状態: 規範外の運用補助。[共通プロンプト](test-planning-prompt.md)と組み合わせて使う。カードは新たな要求、権限、試験義務又は受入判定を作らない。

## 選び方

受入単位と利用目的に合う基本形B01～B06を一つ選ぶ。C07～C20は、G0文書、追加情報、要求又は設計に具体的な該当条件があるものだけを重ねる。該当が不明なら未確認とし、推測で適用しない。各カードの問いは試験の候補を考えるためのもので、一枚につき一件の試験を追加する意味ではない。同じ証拠が複数の問いを支える場合はまとめる。該当しないカードの不採用理由を20件分記録する必要はない。

## 基本形――一つ選ぶ

| ID | 適用の目印 | 考える問い |
|---|---|---|
| B01 全体・機能レビュー | 今回定めた提供範囲全体を、利用者に見せて確認する。 | 利用者が確認する主要な結果と実画面の操作は何か。スタブや未実装の境界はどこか。業務利用可能と誤認させないか。 |
| B02 全体・限定試行 | 提供範囲全体を、指定利用者・期間などを限って試す。 | 誰が、いつ、どのデータと環境で試すか。その範囲で必要な失敗時の停止・復旧は何か。 |
| B03 全体・業務利用 | 今回定めた提供範囲全体を、継続して業務で使う。 | 受入条件の証拠に加え、実際の利用導線と必要な運用条件は成立するか。全経路の個別実行を一律に求めない。 |
| B04 差分・機能レビュー | 既存製品の変更結果を利用者に見せる。 | 変更箇所の結果と、レビューの結論を左右する既存動作への影響は何か。製品全体の再受入と区別できるか。 |
| B05 差分・限定試行 | 既存製品の変更を、指定範囲で試す。 | 変更結果、影響する既存条件、試行範囲、問題時の停止・切戻しをどう対応付けるか。 |
| B06 差分・業務利用 | 変更後の既存製品を業務で使う。 | 差分の結果、必要な関連回帰、既存の全体受入証拠の適合をどう示すか。今回受け入れる範囲はどこまでか。 |

## 追加論点――該当するものだけ重ねる

| ID | 適用の目印 | 考える問い |
|---|---|---|
| C07 UI | 受入条件に画面操作や表示がある。 | 利用者は入口から結果まで実画面で操作できるか。API等の試験で示せる範囲と分ける。 |
| C08 状態遷移 | 開始、拒否、終了、再開などで結果が変わる。 | 受入判断を変える遷移、条件、到達先は何か。同じ結果に至る入力値を無制限に増やさない。 |
| C09 外部連携 | 外部API、イベント又は他システムとの受け渡しがある。 | 送信、受信、適用、失敗時の扱いのうち、今回の受入に関係する境界はどこか。 |
| C10 実データ更新 | データの保存、更新、削除がある。 | 期待する変更、変更してはならない対象、不整合時の扱いを何で確かめるか。模擬結果を実データでの確認済みに広げない。 |
| C11 秘密・個人情報 | 取扱いを制限される情報がある。 | 利用主体、保存、表示、送信先、証拠への混入は適切か。扱わないと確認できれば対象外とする。 |
| C12 権限 | 操作主体や対象資源が分かれる。 | 許可された操作と、受入に影響する拒否を実際の主体・境界で確認できるか。 |
| C13 取り消し困難な作用 | 金銭、公開、削除などの作用がある。 | 実行前の制御、作用した結果、失敗時の処置をどう確認するか。実操作が許可されない場合の未確認範囲は何か。 |
| C14 障害・復旧 | 障害時の継続、停止又は復旧が要求される。 | 検知、停止、通知、復旧先のうち要求された結果は何か。全種類の障害注入を一律に求めない。 |
| C15 長時間実行・再開 | 時間超過、中断、再開があり得る。 | 孤児化、重複実行、再開時の権限・基線・証拠の扱いは受入を変えるか。 |
| C16 性能・容量 | 性能要求又は負荷を伴う利用条件がある。 | 負荷、環境、判定値は要求に結び付くか。要求値がないのに合格閾値を創作しない。 |
| C17 移行 | データ又は利用環境を切り替える。 | 移行対象、変換後の照合、切替条件、失敗時の戻し方は何か。移行を含まない案件には適用しない。 |
| C18 AIの出力・判断 | AI出力が受入又は実際の判断に関わる。 | 用途、評価条件、判定器、評価不能、出力の適用先をどう確認するか。固定例の成功だけで実運用を証明しない。 |
| C19 既存証拠の援用 | 過去の試験や操作記録を今回の判断に使う。 | 版、入力、主体、環境、期待結果は今回と合うか。合う範囲だけを計画表に対応付ける。 |
| C20 スタブ・隔離環境 | 実際の境界を模擬又は隔離して確認する。 | 模擬した入出力と、まだ確認していない接続・作用は何か。今回の利用目的は模擬範囲で達成できるか。 |
