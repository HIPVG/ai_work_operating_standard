# ai_work_operating_standard

AIを用いる作業の目的、権限、証拠、受入条件を明確にし、不要な作業の追加と根拠のない完了報告を抑えるための運用標準です。個別案件での効果は未評価です。

自由に利用・参照・適用してください。自組織への導入、AI支援開発の統制設計、個別案件向けの作業設計、契約・調達の前提整理などで支援が必要な場合は、商用のご相談も歓迎します。
