# 効果評価計画 v0.5

改訂履歴: 2026-09-26 初版／v0.2 選択補助の条件・厚みの観察を追加／v0.3 保存した候補一覧の扱いを追記／v0.5 公開版として整理

状態: 規範外の評価計画

対象: テンプレート又は運用標準を小規模に採用した案件

## 1. 目的と限界

目的は、本体系が実務上の曖昧さ、手戻り、引継ぎ不足、証跡欠損を減らすかを、小さな採用単位で観察することである。採用前に効果を断定せず、少数案件の結果を一般化しない。

比較対象、測定方法、個人情報・顧客情報の扱い、追加調査の許可は案件の決定権者が定める。本計画は調査・計測・保存を許可しない。

## 2. 最小の観察単位

案件又は変更単位ごとに、採用した問い・統合先と、判断に影響した選択理由を残す。未選択の50文書すべてに不採用理由を求めない。可能なら、導入前後で同じ定義を使う。比較不能、未記録、外部要因が大きい場合は、そのまま`NOT EVALUABLE`又は未確認として扱う。

HTML選択補助を用いる場合は、使用版、主要なGiven Conditions、未確認の条件、選んだLoose／Medium／Tight、実際に採用した問いを既存の記録へ追記できる。保存ボタンで候補一覧と回答をJSON／CSVへ出力できるため、選択時点の記録として参照してもよい。自動保存は行わない。出力は候補であり、実際に採用した問いや受入結果は案件側の記録で確認する。厚みは案件規模・リスク区分とは別の変数として扱い、候補数の多寡自体を品質や効果の指標にしない。

| 観察項目 | 定義の例 | 混同しないもの |
|---|---|---|
| 手戻り | 受入条件、範囲、設計の不一致により、合意済みの作業を戻した回数・理由 | 通常の反復、未許可の追加要求 |
| 引継ぎ不足 | 次工程・担当者が、既存記録だけでは判断できず追加確認した件数・理由 | 新規の探索的改善 |
| 証跡欠損 | 受入時に必要とされた根拠、版、責任、結果が追跡できなかった件数 | 事後に任意で増やした資料 |
| 追加負担 | 記録・レビュー・修正に要した時間又は主観的負担 | 成果物のページ数だけ |
| 境界逸脱の抑止 | 範囲・権限・費用に関する不明点を、実行前に判断先へ渡せた事例 | エージェントや作業者の自己申告だけ |
| 選択補助の適切さ | 必要だったのに候補外だった問い、不要だった候補、条件を誤解した事例と理由 | 表示件数の増加、Tightの選択自体 |

## 3. 記録例

| 項目 | 記入例（架空） |
|---|---|
| 対象 | 変更EX-03。既存作業カードへT05、T17、T37の問いを統合。 |
| 比較可能性 | 直前の同種変更は記録粒度が異なるため、件数比較は`NOT EVALUABLE`。 |
| 観察 | 受入前に対象外の連携変更が判明し、実行せず判断先へ渡した。 |
| 負担 | 記録は約15分。正確な計時はしていない。 |
| 解釈 | 境界逸脱の抑止らしき観察はあるが、標準の因果効果は未検証。 |

## 4. 判断と改訂

複数の観察で、特定の問いが繰り返し役に立たない、過重、又は誤解を招くと分かった場合は、根拠・影響・代案を改訂候補として記録する。単発の成功・失敗、文書の存在、テスト終了コード、自己報告だけで本体系の効果を`VERIFIED`としない。

案件の受入結果と、標準・テンプレート体系の有効性評価は別の判断である。
